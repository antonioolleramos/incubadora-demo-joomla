# Incubadora Demo — website demonstrativo

Projeto de portfólio com uma **interface fictícia de incubadora de empresas**, independente e não oficial. A versão pública contém somente HTML, CSS e JavaScript estáticos e demonstra técnicas de personalização visual, design responsivo e organização de páginas originalmente desenvolvidas em um CMS Joomla.

## Executar

Abra `index.html` no navegador ou hospede estes arquivos estáticos no GitHub Pages. Use o menu para navegar entre Início, Notícias, Editais, Empresas, Saiba Mais e Documentos.

## Funcionalidades apresentadas

- Interface responsiva, navegação adaptável, animações e componentes visuais.
- Páginas com cartões de notícias, empresas fictícias, eventos, editais e documentos ilustrativos.
- Formulário de contato visual, sem envio, armazenamento ou processamento de dados.
- Identidade tipográfica criada para a demonstração, sem logos ou imagens institucionais.

| Recurso | Desenvolvimento original com CMS | Prévia de portfólio |
| --- | --- | --- |
| Plataforma | Joomla e PHP, HTML/CSS/JS | HTML/CSS/JS estáticos |
| Publicações | Conteúdo administrado pelo CMS | Cartões ilustrativos |
| Banco e autenticação | Recursos de servidor | Não incluídos |
| Contato | Integrações de servidor | Formulário sem envio |
| Identidade visual | Materiais de projeto institucional | Elementos genéricos |

**Não é um site oficial.** As empresas, informações, documentos, datas, eventos e endereços apresentados são exclusivamente demonstrativos. Não são representações de organizações reais.

## Segurança

Não há credenciais, bases SQL, arquivos PHP de configuração, variáveis de ambiente, endpoints privados, chaves de CAPTCHA ou código de backend neste repositório. A ausência desses recursos aqui não equivale a auditoria de outros sistemas. Leia `SEGURANCA.md`.

Objetivo: demonstrar domínio de interfaces front-end, adaptação de layouts e experiência com CMS.
